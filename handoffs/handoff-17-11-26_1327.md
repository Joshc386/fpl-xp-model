## Process that worked, and lessons (new this session)
1. **CI runs `python -m pytest`, not bare `pytest`,** so `backtest` imports.
2. **Always rebase before you push.** A push was rejected once, behind the
   bot's commit.
3. **Tell agents to run only `ruff check` on files that aren't theirs.**
   Never `ruff format` or `git checkout --` on shared folders. The
   excel-builder reformatted `tests/`, then reverted it with a checkout.
   Nothing was lost.
4. **Personal information:** every workbook build scans for personal
   information and fails on a hit. Scan any new file bound for the public
   repo the same way.
5. **Code Review agents stall on long foreground commands.** Tell them to
   keep each batch under 8 minutes, and resume them with `SendMessage`.
6. Lessons from earlier sessions still apply
   (`handoffs/handoff-15-11-26_1620.md`, "Process that worked").
