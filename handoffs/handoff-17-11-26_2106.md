## Facts that are easy to get wrong
- **The local upstream checkout is at `ac8be9c` (2026-11-13)**, not upstream's
  HEAD.
  - The processed tables, QA's reconciliation and the beyondELO build all
    describe that commit. The workflow always checks out the newest commit.
  - Pulling the checkout changes the processed tables, and then the
    `ext_beyondelo` build would need a re-pull for 2026/27. Delete
    `data/external/beyondelo/raw/matches_2026-2027_p*.json`, which costs 1-2
    requests.
- **The beyondELO API differs from its docs.** `tier` is a string
  (`"domestic_league"`), the Premier League's code is `eng.1`, and 10 club
  names differ from ours (now in `club_aliases`).
  - The season filter returns played matches only.
  - Josh's key is in the user environment variable `BEYONDELO_API_KEY`.
    Never print it or put it on a command line.
- **A new data-integrity check in `clean.py` can break the validator's
  harness.** Its controls corrupt scores in a data copy
  (`backtest/perturb.py`). Check any new check against those controls.
- **Own goals:** neither flagged match had one. One flag was a false positive
  from counting by gameweek (a double gameweek). Check at match level
  (`incidents.csv`, `shots.csv`) before citing.

## Process that worked, and lessons (new this session)
1. **Guard chained shell commands with `set -e`, and check `git diff
   --cached` before committing.** A failed staging script let the next
   commit take every file. It was undone with a soft reset before the push.
2. **Loud stops saved the API quota.** The first real call stopped after one
   request on the unexpected tier, and the cache made every re-run free.
   Design one-off pulls the same way.
3. **A subagent hit the 5-hour usage limit mid-task.** Resume it with
   `SendMessage` once the limit resets. Its saved work, such as a finished
   suite log, carries over.
4. **Three agents appending to `docs/decisions.md` at once worked,** but
   check that every entry survived afterwards.
5. **Main-session review was used for tests-and-checklist-only fixes,** by
   Josh's decision. Code changes still go through Code Review.
6. **Lessons from earlier sessions still apply**
   (`handoffs/handoff-17-11-26_1327.md` and `handoff-15-11-26_1620.md`,
