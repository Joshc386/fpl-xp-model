## Process that worked, and lessons (new this session)
1. **A session end kills background work.** The full suite died at 66% with
   no failures and reported exit code 4. Read the log before calling it a
   failure, and rerun. Resume a stopped agent with `SendMessage` to its name;
   its transcript carries over.
2. **Three commits out of one file:** `git add -p` isn't available. Build each
   version of the file, then `git hash-object -w --path=<file>` and
   `git update-index --cacheinfo`, and check `git diff --cached` every time.
3. **Ask reviewers to mutate the code.** Code Review broke the check 15 ways
   and found the one untested path, the line search.
4. **Recheck figures by a different method before citing them.** A
   Nelder-Mead fit matched the validator's Newton fit to 4 decimals, then the
   analysis-verifier confirmed the whole report.
5. **A `cd` into a subfolder moves the session's working directory.** Use
   absolute paths, or `cd` back to the project root.
6. Lessons from earlier sessions still apply (`handoffs/handoff-17-11-26_2106.md`,
   "Process that worked").
