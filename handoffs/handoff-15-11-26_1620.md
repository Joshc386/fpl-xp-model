## Process that worked, and lessons
1. **Check every agent report against the data yourself,** with your own
   script that shares no code with the agent's. Every number this session
   reproduced exactly. Scratch scripts live in the session's scratchpad and
   don't carry over.
2. **Code Review uses a general-purpose agent with the Code Review role**
   from `~/.claude/Agent_Roster.md`. It runs mutation testing on scratch
   copies and an independent spot check. Resume the same reviewer for its
   second and third passes, since it keeps its context.
3. **Commit approved code, then the review follow-ups,** as separate
   commits. When other agents' uncommitted files are in the tree, check the
   intermediate commit in a detached worktree:
   `git worktree add --detach <scratch> HEAD`, copy in the files, then run
   pytest with `PYTHONPATH=<scratch>/src`.
4. **Staging only part of `docs/decisions.md`:** build HEAD plus the one
   entry, `git hash-object -w`, then `git update-index --cacheinfo`.
   - **Line endings:** Python's `write_text` writes CRLF on Windows, so use
     `newline="\n"` or `sed -i 's/\r$//'`. The repo stores LF.
   - **Order:** HEAD's entry order can differ from the working tree's, so
     compare entries, not whole files.
5. **Independence:**
   - `main -` entries never quote the modeller's accuracy numbers or
     reasoning, because the validator reads them.
   - Give the modeller only development-window (2025/26) findings, and tell
     it not to read `backtest/reports/`.
   - The validator's reading list excludes `model -` entries.
6. **Agents hit the 5-hour usage limit four times.** Resume them with
   `SendMessage` to their name; their files are kept. Names don't carry over
   to a new session.
7. **Tell every agent never to kill processes globally.** A data-engineer
   ran `taskkill //IM python.exe`, which killed every Python process on the
   machine.
8. **Agents append to `docs/decisions.md`:** tell them to add only their
   own entries at the end. One wrote inside a committed `main -` entry.
